# Madrid Traffic Accidents 2025

Exploratory analysis and visual storytelling based on the official traffic-accident dataset published by Madrid City Council.

## Scope

- **51,067** person-level records.
- **21,688** unique accidents.
- Temporal, geographic, vehicle, injury, weather and alcohol-related analysis.
- Fifteen visualisations organised around exposure, conflict, vulnerability, contributing factors and prevention.

## Key analytical principles

- Separate accident-level and person-level counts.
- Report rates with their denominators, not only absolute totals.
- Treat observed relationships as associations rather than causal effects.
- Document data-quality limitations and missing values.
